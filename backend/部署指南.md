# Phase 1 部署指南 - 5 步走完

> 全部代码已写在 `backend/` 目录下。你只需手动操作 Cloudflare 几次（10 分钟）。

---

## Step 1：建 D1 数据库（2 分钟）

1. 打开 https://dash.cloudflare.com/
2. **Workers & Pages** → **D1 SQL Database** → **Create database**
3. 名字填 `api-youxuan-db`
4. 创建后**复制 Database ID**（形如 `xxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`）
5. 写入 `backend/worker/wrangler.toml` 的 `database_id`

---

## Step 2：初始化 Schema（1 分钟）

**方法 A（用 Cloudflare 仪表盘）**：
- 进入 `api-youxuan-db` → **Console** 标签
- 复制 `backend/migrations/001_init_schema.sql` 全部内容
- 粘贴到 Console → 点击 **Execute**
- 重复执行 `backend/migrations/002_admin_users.sql`

**方法 B（用 wrangler 命令行，**更快**）**：
```bash
cd backend/worker
npm install -g wrangler    # 如果还没装
wrangler login            # 浏览器登录
wrangler d1 execute api-youxuan-db --file=../migrations/001_init_schema.sql --remote
wrangler d1 execute api-youxuan-db --file=../migrations/002_admin_users.sql --remote
```

---

## Step 3：部署 Worker（2 分钟）

```bash
cd backend/worker
npm install
wrangler deploy
```

部署成功后会有输出：
```
Published api-youxuan-api
  https://api-youxuan-api.YOUR_SUBDOMAIN.workers.dev
```

**记下这个 URL**，下面要用。

---

## Step 4：设置环境变量

**方法 A（仪表盘）**：
- 进入 Worker → **Settings** → **Variables**
- 添加：
  - `ADMIN_TOKEN` = `apiradar-admin-2026-secret-token`（**自定义一个**）

**方法 B（命令行）**：
```bash
wrangler secret put ADMIN_TOKEN
# 提示输入值时粘贴你的 token
```

---

## Step 5：测试 Worker

### 测试公开读（不需要 token）
```bash
curl https://api-youxuan-api.YOUR_SUBDOMAIN.workers.dev/api/data
```
应该返回 `{"error":"..."}` 或空数据 `{"vendors":[],...}`（数据库空，正常）。

### 测试后台写（需要 token）
```bash
TOKEN=apiradar-admin-2026-secret-token

curl -X POST https://api-youxuan-api.YOUR_SUBDOMAIN.workers.dev/api/admin/vendors \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"id":"v_test","name_zh":"测试厂商","region":"global"}'
```

如果返回 `{"ok":true}` 说明 CRUD 工作正常。

## Step 6：导入种子数据

```bash
python import_seed.py \
  https://api-youxuan-api.YOUR_SUBDOMAIN.workers.dev \
  $TOKEN
```

应该导入：

- 60 个模型
- 40 个渠道
- 1289 个提供关系
- 13 个事件

---

## Step 7：把 Worker 绑到 api.apiyouxuan.top（可选）

现在 Worker URL 是 `https://api-youxuan-api.YOUR_SUBDOMAIN.workers.dev`。

**漂亮做法**：绑自定义域名 `api.apiyouxuan.top`。

1. Worker → **Settings** → **Triggers** → **Custom Domains**
2. 添加 `api.apiyouxuan.top`
3. Cloudflare 自动加 CNAME 记录

之后前台用 `https://api.apiyouxuan.top/api/*` 访问。

## 出问题怎么办

| 现象 | 原因 | 解决 |
|---|---|---|
| 401 Unauthorized | token 不对 | 检查 wrangler secret list |
| 500 Table not found | 没跑 schema | 重跑 Step 2 |
| INSERT 失败 | 字段缺失 | 跑 `wrangler d1 execute api-youxuan-db --command="SELECT * FROM models LIMIT 1" --remote` 看实际字段 |
| 跨域错误 | Worker 没 CORS | 已经在代码里了，部署后自动生效 |
