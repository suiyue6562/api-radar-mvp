📋 数据方法

v0.1 · 2026-09-20

1. 数据来源

价格数据来自以下三类来源（按可信度排序）：

等级来源前台规则
A官方公开页面或官方 API正常展示，可参与排序
B渠道自有页面，主体已认领正常展示，标明"渠道来源"
C可靠二手或多来源一致展示为参考，不用于关键推荐
D单一非官方或已过期待验证，不参与排序

2. 价格标准化

  • 所有价格统一换算为 人民币 / 百万 Token（除显式标注的"美元"展示）
  • 原始币种和汇率日期保留，用于审计
  • 输入、输出、缓存读写、批量处理分别计价，不混入单一总价
  • 阶梯价、长上下文附加费、促销价显示适用条件和有效期
  • 汇率：2026-09-20 USD/CNY = 7.10

3. 更新机制

  • 公开价格：每日自动检查，7 天未验证标记"待验证"并退出默认推荐
  • 模型能力：每周检查，30 天未验证进入复核队列
  • 渠道采购字段：每月检查，90 天未验证显示"待更新"
  • 故障状态：5-15 分钟采集或官方事件触发，恢复后归档为历史事件

4. 渠道三栏分列原则

每个渠道详情页强制三栏独立展示，禁止用单一星级掩盖：

栏位包含来源
技术表现API 格式、SLA、可用率、延迟官方 + P1 后才有实测
商业条件付款、发票、合同、最低充值服务商声明
政策证据数据区域、训练、日志保留服务商政策页 + 日期

5. 实测数据（当前版本）

⚠️ v0.1 暂未集成实测引擎。所有"可用率""延迟"等数据待 P1 阶段上线后再展示。

6. 免责声明

本网站信息用于选型参考，不构成对渠道的保证、法律意见或采购承诺。价格和能力可能变化，请以官方页面为准。任何已知错误将通过纠错入口处理，重大争议先降级展示再复核。

7. 已知限制

  • 字段完整度约 70%（广覆盖版 MVP，详见 PRD v1.1）
  • 未集成实测数据，仅展示服务商声明
  • 关注列表使用浏览器 localStorage，不跨设备同步
  • 计算器为估算，实际以渠道账单为准
