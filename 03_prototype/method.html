⚖️免责声明

本站追求中立透明，但以下情况需要您理解数据边界。

⚠ 数据局限
  • 价格数据每周刷新一次，最新变动可能延迟 1-7 天（厂商不通知即变价）
  • 用户评论为公开内容摘录，已尽量隐去可识别信息，但不代表全体用户意见
  • 能力基准基于公开榜单，不同榜单加权差异会导致排名变化
  • 渠道可用性受地域 / 网络环境影响，实际表现以您本机为准
  • 本站不提供 API 中转服务，亦不与任何渠道存在商业合作
  • 数据仅供研究参考，不构成任何投资或采购建议

🛡️ 争议处理流程

  1. 发现数据错误？请发 Issue 到 github.com/api-radar/data 或邮件至 hello@api.radar
  2. 我们 48 小时内回复 · 核实后 7 天内更新
  3. 重大错误会立即修正并公告（事件时间线）
  4. 不接受厂商 PR 改写自家负面评价，但欢迎补充客观数据
