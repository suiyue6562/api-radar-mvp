> 调研日期：2026年9月20日

---

## 选渠道的原则

| 维度 | 要求 | 原因 |
|---|---|---|
| **来源可验证** | 有公开价格页或 API 文档 | 字段完整度 ≥ 70% 的前提 |
| **覆盖目标用户** | 主要面向编程/Agent 场景的开发者 | 首版聚焦独立开发者与小团队 |
| **类型分布** | 官方×2 + 云厂商×2 + 聚合平台×5 + 国内渠道×6 | PRD 要求的渠道类型多样性 |
| **风险分级** | 含高/中/低风险三级 | 三栏分列原则（技术/商业/政策） |
| **付款条件** | 优先人民币支付 | 目标用户国内开发者为主 |

**不收录**：不合规中转站（见 `不合规API中转站完整清单_20260920.xlsx` 排除列表）
