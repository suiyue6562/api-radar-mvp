# 不合规中转站收录标准与要素

> **文档版本**：v1.0 · 2026-09-21
> **维护方**：API优选咨询 · 内容审核组
> **适用读者**：录入员、审核员、合作方
> **存放路径**：`01_docs/gray_market_collection_standards.md`

## 1. 项目背景

**API优选咨询** 是一个**中立第三方信息发布站**，定位如下：

- **我们不提供中转服务**，不代理任何 API 流量，不充值返佣，不做交易撮合。
- **我们只发布公开信息**：把散落在 Reddit、Telegram、GitHub、第三方榜单上的 AI API 中转站情报结构化、可对比、可检索。
- **服务对象**：希望了解全网 AI API 中转站市场的开发者、独立创业者、采购负责人。
- **商业底线**：信息中立 · 不为收录站导流 · 不为收录站背书 · 不收录入驻费。

> 一句话定位：**「开发者版的灰产市场透明化目录」**——只做镜子，不做货架。

## 2. 收录原则

### 2.1 总原则

> **只收录「公开可访问 + 有真实用户使用 + 信息可客观评估」的网站。**

### 2.2 必须收录的条件（满足全部）

| 条件 | 说明 |
|---|---|
| 公开可访问 | 域名可正常打开，无需邀请码/内测资格/翻墙 |
| 有用户使用 | 在 RelayPick / Veridrop / AIAPIRank / Reddit / Telegram 群任一公开渠道有真实讨论或排名 |
| 价格可查 | 网站前台或注册后能直接看到定价（不必登录也可看倍率） |
| 信息可核验 | 至少 2 个独立信息源可交叉验证其存在与运营状态 |

### 2.3 不收录的情形（命中任一即排除）

- ❌ **纯骗局 / 诈骗站**（收款后跑路、被举报欺诈）
- ❌ **只通过电话 / 微信私聊联系**（无公开网址或仅有落地页）
- ❌ **纯私密群组流传的内部渠道**（仅 Telegram 群机器人，无独立站点）
- ❌ **必须付费才能查看定价**（无法做客观比较，违反中立原则）
- ❌ **已被国家工信部明令封禁**（参考工信部公开通报清单）
- ❌ **明确从事违法违规业务**（洗钱、盗刷、未授权转售等）
- ❌ **盗用正规厂商品牌且无真实服务**（仿冒 OpenAI/Anthropic 域名但实为空壳）

### 2.4 收录边界（灰区判断）

| 场景 | 是否收录 | 处理方式 |
|---|---|---|
| 自称"正规渠道"但实际绕过区域限制 | ✅ 收录 | 标注"合规属性：风险" |
| 仅服务海外华人市场但运营在国内 | ✅ 收录 | 标注"地区：国内运营/海外服务" |
| 支持 USDT 但其他维度合规 | ✅ 收录 | 在支付方式如实标注 |
| 已被某国封禁但其他地区可访问 | ✅ 收录 | 标注"地区限制"字段 |

## 3. 必填数据点（10 项）

每个被收录站点必须填齐以下 10 项，缺一项不进入公开列表，仅进入内部候选池。

### 3.1 数据点清单

| # | 数据点 | 为什么需要 | 主要采集源 | 示例 |
|---|---|---|---|---|
| 1 | **站点名称** | 用户识别品牌 | 站点首页 / Title 标签 / 关于我们 | `AnyRouter` |
| 2 | **域名 / 入口** | 用户直接访问；用于后续核验 | 站点底部、ICP 公示、第三方榜单跳转链 | `https://anyrouter.top` |
| 3 | **地区** | 决定 ICP / 法律风险标注 | WHOIS + 服务器 IP 归属 + 公司主体公示 | `国内运营 / 海外服务` |
| 4 | **合规属性** | 核心筛选维度 | 人工判定（基于支付方式、运营主体、宣传话术） | `不合规 / 风险` |
| 5 | **主要支持模型** | 开发者最关心字段 | 站点模型列表页（实时截图） | `GPT-4o, Claude 3.5, DeepSeek-V3, Gemini 1.5 Pro` |
| 6 | **价格倍率** | 性价比核心指标 | 站点定价页 → 计算 `（本站价 / 官方价）` | `0.38x`（即官方价的 38%） |
| 7 | **支付方式** | 影响可达性、合规风险 | 站点充值页 / FAQ | `支付宝, USDT, 微信` |
| 8 | **数据来源** | 信息溯源，便于复核 | 第一次收录时的来源榜单/帖文 | `RelayPick 2026-08 榜单 #3` |
| 9 | **首次出现时间 / 上线时间** | 评估站点成熟度 | Wayback Machine 最早快照、第三方榜单首次收录日 | `2026-04-12` |
| 10 | **最近验证时间** | 让用户知道信息新旧 | 我们最后一次实际访问测试的时间戳 | `2026-09-21 14:30 UTC+8` |

### 3.2 字段规范

- **价格倍率**：统一以官方价（厂商官网公开标准定价）为分母，保留 2 位小数。如官方价缺失则标注 `N/A`，并在备注栏说明估算逻辑。
- **地区**：三档取值：`国内` / `海外` / `国内运营，海外服务`。
- **合规属性**：二档取值：`不合规`（明确绕过区域/合规限制）/ `风险`（合规性存疑，介于白与灰之间）。
- **最近验证时间**：精确到分钟，由系统自动记录采集动作完成时间。

## 4. 可选数据点（7 项）

鼓励填齐；缺失时以 `未知` 展示，不阻塞收录。

| # | 数据点 | 采集源 | 说明 |
|---|---|---|---|
| 1 | **最低充值金额** | 站点充值页 | 影响试用门槛 |
| 2 | **退款政策** | 服务条款 / FAQ | `7天无理由 / 不支持 / 仅余额不退` |
| 3 | **是否支持发票** | 客服对话 / FAQ | 绝大多数不合规站不支持 |
| 4 | **退款手续费** | 退款条款 | 用于估算实际损失 |
| 5 | **在线率（30天）** | 我们自建探针 | 抽样每日 4 次 GET `/` |
| 6 | **平均延迟（秒）** | 我们自建探针 | 国内出口 → 站点 → OpenAI 官方 API 的端到端 |
| 7 | **用户评价（可信第三方）** | Reddit r/ChatGPT、AINodes、Telegram 公开群 | 仅采信带订单截图或具体场景的评论 |

> 探针类指标（在线率 / 延迟）必须由我们自建，不采信站点自报数据。

## 5. 信息源

我们从以下公开渠道获取候选站点；任何一条线索都要回到至少 2 个独立源交叉验证才进入收录流程。

### 5.1 主要榜单

| 来源 | URL | 特点 |
|---|---|---|
| **RelayPick** | `https://relaypick.com`（占位） | 更新频率高，按价格倍率排名 |
| **Veridrop** | `https://veridrop.io`（占位） | 偏重稳定性评测，有在线率数据 |
| **AIAPIRank** | `https://aiapirank.net`（占位） | 综合榜，含用户投票 |

### 5.2 社区源

- Reddit：`r/ChatGPT`、`r/LocalLLaMA`、`r/OpenAI`
- Telegram 公开群：`@api_resell_chat` 类（占位）
- GitHub：`awesome-api-reseller` 类列表仓库
- V2EX、NodeSeek、HOSTLOC 相关板块

### 5.3 自有探针

- 域名 WHOIS 变更监控
- 价格倍率变动监控（每日爬）
- 站点存活探针（30 分钟一次）

### 5.4 信息源冲突处理

| 场景 | 处理 |
|---|---|
| A 源显示价格 0.38x，B 源显示 0.45x | 以最新一次自建采集为准；保留 A、B 两条原始记录备查 |
| A 源说"已跑路"，B 源说"在运营" | 立刻人工验证，探针连测 3 次 |
| 无任何中文 / 英文公开讨论 | 暂不收录，进入"观察池"满 30 天后再评估 |

## 6. 更新频率

| 数据点 | 更新频率 | 实现方式 |
|---|---|---|
| **价格倍率** | **每月 1 次** | 定时爬取 + 人工复核 |
| **支付方式** | **每月 1 次** | 同上 |
| **主要支持模型** | **每月 1 次** | 同上 |
| **在线率 / 平均延迟** | **每周抽样**（每日 4 次） | 自建探针后台自动跑 |
| **最近验证时间** | **每次访问后立即更新** | 系统自动打时间戳 |
| **首次出现时间** | 仅写入一次 | 从 Wayback Machine 锁定后不再改 |
| **完整信息 review** | **每季度 1 次** | 人工 + 探针报告联合 review |
| **被封 / 跑路响应** | **发现后 24 小时内处理** | 立即从公开列表删除或标记为 🔴/⚫ |

## 7. 状态标记

每个被收录站点都有一个状态字段，对应不同颜色的 emoji 图标：

| 图标 | 状态 | 定义 | 列表展示 |
|---|---|---|---|
| 🟢 | **活跃** | 30 天内有真实交易信号（订单、用户讨论、价格变动） | 正常展示 |
| 🟡 | **不确定** | 30–90 天无明显活动迹象 | 正常展示，加灰色备注 |
| 🔴 | **已跑路** | 90 天以上无响应 / 域名失效 / 探针全失败 | 移到列表底部，加显眼警示 |
| ⚫ | **已封禁** | 被官方（工信部 / Apple / Google 等）明令封禁 | 默认隐藏，仅在用户主动展开"封禁历史"时显示 |

**状态变更规则**：

- 🟢 → 🟡：30 天无任何活动信号触发
- 🟡 → 🔴：再 60 天（共 90 天）无响应触发
- 任何状态 → ⚫：收到权威封禁通报立刻触发
- 🔴 / ⚫ → 🟢：必须有连续 7 天探针全活 + 价格页面可访问 + 至少 1 个第三方源提及恢复

## 8. 访问限制

为规避潜在法律风险，对灰产市场相关页面施加以下访问限制：

### 8.1 地域限制

- **仅限中国大陆以外用户访问**（基于 IP 地理位置判断）。
- 境内 IP 访问灰产相关页面统一返回「该内容不在您所在地区提供」的中性提示，不暴露具体 URL。
- 管理员后台不受地域限制（需 VPN + 二次验证）。

### 8.2 用户确认

- 用户首次访问灰产列表前，**必须勾选「我已了解使用此类服务的潜在风险（包括但不限于：资金损失、隐私泄露、账号被封禁）」** 才能查看。
- 勾选状态写入 cookie，30 天有效；到期重新提示。

### 8.3 展示规则

- 不展示任何充值链接、二维码、邀请码、Affiliate 链接。
- 所有跳转链接均带 `rel="nofollow noopener"` 且经过中间跳转页，提示「即将离开本站」。
- 不在站外 SEO 索引灰产列表页（`noindex`）。

## 9. 收录流程（补充）

```
候选发现 → 初步筛选（公开可访问 + 有用户使用）
  ↓
交叉验证（≥2 个独立源）
  ↓
填齐 10 项必填数据 → 进入候选池
  ↓
审核员人工复核 → 标记合规属性 & 状态
  ↓
灰产列表页发布（受访问限制）
  ↓
定时巡检 → 状态自动更新
```

审核员拒绝收录时，必须填写拒绝原因（最少 20 字），便于后续追溯。

## 附录 A：术语表

| 术语 | 含义 |
|---|---|
| **中转站 / Reseller** | 批量采购官方 API 额度后，以倍率（通常更低）分销给终端用户的中间方 |
| **倍率（x）** | 本站价格 ÷ 官方价格。`0.38x` 表示按官方价 38% 出售 |
| **不合规** | 明确违反上游厂商 ToS 或所在国法规（如绕过区域限制、未授权转售） |
| **风险** | 合规性存疑、介于白与灰之间、信息不足难以判定 |
| **跑路** | 站点停止运营且未退还用户余额 |
| **探针** | 我们部署在境外的轻量 HTTP 客户端，用于定时检测站点可达性 |
