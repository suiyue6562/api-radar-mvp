# API优选咨询 管理后台设计文档

> **目标**：让陈涛能不碰代码、不动 Git、不重启服务器，**直接改任何前台数据**。
> **未来扩展**：支持广告位管理、点击统计、A/B 测试、内容运营。

---

## 0. 现状审查

### 数据现状
| 维度 | 来源 | 数量 | 改的方式 |
|---|---|---|---|
| 厂商 vendors | seed_data.json | 21 | 编辑器改 → git push → 服务器 pull |
| 模型 models | seed_data.json | 60 | 同上 |
| 渠道 providers | seed_data.json | 40 | 同上 |
| 价格倍数 offerings | seed_data.json | 1289 | 同上 |
| 事件 events | seed_data.json | 13 | 同上 |
| 用户关注 watch | localStorage | 不限 | 用户自己的浏览器 |
| 测试历史 test | localStorage | 不限 | 用户自己的浏览器 |

### 渲染逻辑现状
- 全部前端渲染（HTML/JS/CSS，无后端 API）
- 数据通过 `data.js` 注入到全局 `API_RADAR_DATA`
- 静态文件由 `python -m http.server 8080` 提供

### 痛点
1. ❌ **改任何字段要编辑器+git push+等 cron**（10 分钟延迟）
2. ❌ **没有审计日志**（不知道谁改了啥）
3. ❌ **没有版本回滚**（改错了要靠 git log 找回）
4. ❌ **没有 A/B 能力**（想试新版首页只能改代码）
5. ❌ **没有广告位管理**（后期想赚钱不能直接插）
6. ❌ **没有访问统计**（不知道有多少人用、用了啥）

## 1. 架构选择（**核心决策**）

### 三个候选方案

| 方案 | 工作量 | 能力上限 | 适合阶段 |
|---|---|---|---|
| **A. 纯前端**（localStorage） | 小 | 单人、单机、静态 | ❌ 你不要 |
| **B. GitHub API** | 中 | 多设备、自动提交 | ❌ 你不要 |
| **C. Cloudflare D1 + Worker** | 中 | 真数据库、可扩展 | ✅ **选这个** |

**选 C 的理由**：
- 你已经有 Cloudflare 账号 + 域名 + 隧道（基础设施零成本）
- D1 是免费 SQLite（5GB 存储、500 万次读/天）
- Worker 是免费 10 万次请求/天
- 后期广告点击统计、A/B 测试、邮件订阅都用得上
- 一次配置终身用

## 3. 数据模型（SQLite Schema）

```sql
-- 厂商
CREATE TABLE vendors (
  id TEXT PRIMARY KEY,
  name_zh TEXT NOT NULL,
  name_en TEXT,
  region TEXT CHECK(region IN ('global','cn')),
  logo TEXT,
  website TEXT,
  data_status TEXT DEFAULT 'B',  -- A/B/C 完整度
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 模型
CREATE TABLE models (
  id TEXT PRIMARY KEY,
  vendor_id TEXT NOT NULL REFERENCES vendors(id),
  name TEXT NOT NULL,
  display_name TEXT,
  family TEXT,
  category TEXT,  -- reasoning/balanced/coding/multimodal
  tags TEXT,  -- JSON array
  context_window INTEGER,
  max_output_tokens INTEGER,
  release_date TEXT,
  price_input_per_m REAL,
  price_output_per_m REAL,
  price_cache_read_per_m REAL,
  tool_use INTEGER DEFAULT 0,
  vision INTEGER DEFAULT 0,
  json_mode INTEGER DEFAULT 1,
  function_calling INTEGER DEFAULT 0,
  streaming INTEGER DEFAULT 1,
  batch_discount REAL DEFAULT 0.5,
  long_context_premium TEXT,  -- JSON
  modality TEXT,  -- JSON array
  scenes TEXT,  -- JSON array
  description TEXT,
  notes TEXT,
  license TEXT,
  is_open_weight INTEGER DEFAULT 0,
  data_status TEXT DEFAULT 'B',
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_models_vendor ON models(vendor_id);

-- 渠道
CREATE TABLE providers (
  id TEXT PRIMARY KEY,
  name_zh TEXT NOT NULL,
  name_en TEXT,
  type TEXT CHECK(type IN ('official','aggregator','gateway','self_host','platform','individual')),
  region TEXT,
  website TEXT,
  payment_currency TEXT,  -- JSON array
  invoice_available INTEGER DEFAULT 0,
  min_charge REAL DEFAULT 0,
  sla_uptime TEXT,
  concurrent_rpm INTEGER,
  api_protocol TEXT,  -- JSON array
  regions_available TEXT,  -- JSON array
  notes TEXT,
  data_status TEXT DEFAULT 'B',
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 提供关系（模型×渠道 的售价）
CREATE TABLE offerings (
  model_id TEXT NOT NULL REFERENCES models(id),
  provider_id TEXT NOT NULL REFERENCES providers(id),
  is_official INTEGER DEFAULT 0,
  multiplier REAL DEFAULT 1.0,
  input_usd_m REAL,
  output_usd_m REAL,
  cache_read_usd_m REAL,
  source_url TEXT,
  PRIMARY KEY (model_id, provider_id)
);

-- 事件
CREATE TABLE events (
  id TEXT PRIMARY KEY,
  date TEXT NOT NULL,
  event_type TEXT NOT NULL,  -- price_change/new_model/outage/capability_update/policy_change/model_deprecate
  severity TEXT,  -- high/medium/low/positive/neutral
  target_type TEXT,  -- model/provider
  target_id TEXT,
  target_name TEXT,
  title TEXT NOT NULL,
  description TEXT,
  tags TEXT,  -- JSON array
  source_urls TEXT,  -- JSON array
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_events_date ON events(date DESC);

-- 广告位
CREATE TABLE ads (
  id TEXT PRIMARY KEY,
  slot TEXT NOT NULL,  -- home_top/home_mid/models_top/sidebar 等
  type TEXT,  -- banner/text/sponsored_card
  title TEXT,
  content TEXT,
  image_url TEXT,
  link_url TEXT,
  advertiser TEXT,  -- 广告主
  start_date TEXT,
  end_date TEXT,
  active INTEGER DEFAULT 1,
  priority INTEGER DEFAULT 0,  -- 多个广告同位时优先级
  max_impressions INTEGER,  -- 限额
  impressions INTEGER DEFAULT 0,
  clicks INTEGER DEFAULT 0,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_ads_slot ON ads(slot, active);

-- 广告点击（用于统计）
CREATE TABLE ad_clicks (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  ad_id TEXT NOT NULL,
  ts TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  user_agent TEXT,
  country TEXT,
  referer TEXT
);

CREATE INDEX idx_ad_clicks_ad ON ad_clicks(ad_id, ts);

-- 页面浏览（用于统计）
CREATE TABLE page_views (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  path TEXT NOT NULL,
  ts TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  user_agent TEXT,
  country TEXT
);

-- 关注列表（替代 localStorage，多设备同步）
CREATE TABLE watches (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_token TEXT NOT NULL,  -- 匿名用户 ID
  target_type TEXT,  -- model/provider
  target_id TEXT,
  target_name TEXT,
  notify_email TEXT,  -- 可选邮箱订阅
  notify_telegram TEXT,  -- 可选 TG 订阅
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  UNIQUE(user_token, target_type, target_id)
);

CREATE INDEX idx_watches_user ON watches(user_token);

-- 后台账号
CREATE TABLE admin_users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  username TEXT UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,  -- bcrypt
  role TEXT DEFAULT 'editor',  -- admin/editor/viewer
  api_token TEXT,  -- 用于 Worker 验证
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  last_login TIMESTAMP
);

-- 审计日志（关键！所有修改记录）
CREATE TABLE change_log (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER,
  action TEXT,  -- create/update/delete
  table_name TEXT,
  record_id TEXT,
  old_value TEXT,  -- JSON
  new_value TEXT,  -- JSON
  ip_address TEXT,
  ts TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_change_log_ts ON change_log(ts DESC);
CREATE INDEX idx_change_log_table ON change_log(table_name, record_id);
```

## 4. Worker API 设计

### 公开读 API（前台用）

```
GET  /api/data                       → 全部数据快照 {vendors, models, providers, offerings, events, ads}
GET  /api/models                     → 模型列表
GET  /api/models/:id                 → 单个模型 + offerings
GET  /api/providers                  → 渠道列表
GET  /api/providers/:id              → 单个渠道
GET  /api/events?days=30             → 最近事件
GET  /api/ads?slot=:slot             → 该位置的广告
POST /api/ads/:id/click              → 广告点击统计（+1）
POST /api/page-view                  → 页面浏览统计
POST /api/watches                    → 添加关注（带 user_token）
DELETE /api/watches/:id              → 删除关注
GET  /api/watches?user_token=:t      → 拉取关注列表
```

### 后台写 API（管理用，需 Bearer Token）

```
POST   /api/admin/vendors            → 新建
PATCH  /api/admin/vendors/:id        → 更新
DELETE /api/admin/vendors/:id        → 删除

POST   /api/admin/models             → 新建
PATCH  /api/admin/models/:id         → 更新
DELETE /api/admin/models/:id         → 删除

POST   /api/admin/providers          → 新建
PATCH  /api/admin/providers/:id      → 更新
DELETE /api/admin/providers/:id      → 删除

PATCH  /api/admin/offerings          → 批量更新价格倍数
POST   /api/admin/offerings/bulk     → 批量替换

POST   /api/admin/events             → 新建
PATCH  /api/admin/events/:id         → 更新
DELETE /api/admin/events/:id         → 删除

POST   /api/admin/ads                → 新建广告位
PATCH  /api/admin/ads/:id            → 更新
DELETE /api/admin/ads/:id            → 删除

GET    /api/admin/log                → 审计日志
GET    /api/admin/stats              → 仪表盘数据
POST   /api/admin/export             → 导出 seed_data.json
```

## 6. 前台接入（前端改造）

### 6.1 data.js 改造

旧版：直接 inject 静态 JSON
```js
const API_RADAR_DATA = { vendors, models, providers, offerings, events };
```

新版：拉 Worker API（带缓存）
```js
async function loadData() {
  const cached = localStorage.getItem('api_youxuan_data_cache');
  const cacheTime = localStorage.getItem('api_youxuan_data_cache_ts');
  
  // 5 分钟内用缓存
  if (cached && Date.now() - cacheTime < 5 * 60 * 1000) {
    return JSON.parse(cached);
  }
  
  // 否则拉新
  const resp = await fetch('https://api.apiyouxuan.top/api/data');
  const data = await resp.json();
  
  localStorage.setItem('api_youxuan_data_cache', JSON.stringify(data));
  localStorage.setItem('api_youxuan_data_cache_ts', Date.now());
  
  return data;
}
```

### 6.2 广告位渲染

在首页 HTML 中预留：
```html
<div id="ad-slot-home_top"></div>
```

JS 自动填充：
```js
async function loadAd(slot) {
  try {
    const resp = await fetch(`https://api.apiyouxuan.top/api/ads?slot=${slot}`);
    const ad = await resp.json();
    if (!ad) return;
    
    const html = renderAd(ad);
    document.getElementById(`ad-slot-${slot}`).innerHTML = html;
    
    // 点击统计
    document.getElementById(`ad-slot-${slot}`).addEventListener('click', () => {
      fetch(`https://api.apiyouxuan.top/api/ads/${ad.id}/click`, {method:'POST'});
    });
  } catch(e) {
    // 静默失败（广告不是主功能）
  }
}
```

### 6.3 关注列表多设备同步

旧版：localStorage（单设备）
新版：
```js
// 用户首次访问生成匿名 token
const userToken = localStorage.getItem('user_token') || 
  (() => { const t = crypto.randomUUID(); localStorage.setItem('user_token', t); return t; })();

// 同步关注列表
async function syncWatches() {
  await fetch('https://api.apiyouxuan.top/api/watches', {
    method: 'POST',
    headers: {'Content-Type': 'application/json'},
    body: JSON.stringify({
      user_token: userToken,
      target_type, target_id, target_name
    })
  });
}
```

## 7. 子域名分配

| 子域名 | 用途 | 部署 |
|---|---|---|
| `apiyouxuan.top` / `www.apiyouxuan.top` | 前台 | Cloudflare Tunnel → 服务器 8080 |
| `admin.apiyouxuan.top` | 管理后台 | 同一个 8080 端口 + URL 路由（/admin.html） |
| `api.apiyouxuan.top` | Worker API | Cloudflare Worker + D1 |

**简化**：3 个子域名都解析到同一个隧道，Worker 在 Cloudflare 边缘做路由分发。

## 11. 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| D1 写超限（5GB） | 数据丢失 | 监控 + 定期导出备份 |
| Worker 调用超限（10 万/天） | 统计丢失 | 前台批量上报（每 30 秒一次） |
| 后台密码泄露 | 数据被改 | bcrypt + 限流 + 改密码 + 审计日志 |
| 前台 API 拉取失败 | 显示空白 | localStorage 缓存 + 默认数据 fallback |
| 广告客户违规内容 | 法律风险 | 后台审核（人工 review 才能 active=1） |
| 数据迁移出错 | 数据不一致 | 灰度切换 + 对比 + 一键回滚 |
